# ⚔️ CRISIS-LABORATORY

### Debugging Arena | Sree Sakthi Engineering College

**CRISIS-LABORATORY** is an interactive debugging arena designed to challenge students' programming skills, logical thinking, and debugging abilities. Conducted at **Sree Sakthi Engineering College**, the arena takes participants through multiple difficulty levels, from beginner-friendly bugs to advanced challenges.

The platform makes debugging more engaging by combining progressive difficulty, challenge-based problem solving, and a special **Boss Challenge** unlocked by meeting specific performance conditions.

---

## 🎯 About the Arena

CRISIS-LABORATORY provides a structured environment where participants identify errors, analyze code, and solve debugging challenges.

Participants progress through four challenge categories:

| Level | Description |
|---|---|
| 🟢 **Easy** | Beginner-friendly bugs to test fundamental programming knowledge |
| 🟡 **Medium** | Intermediate debugging challenges requiring logical thinking |
| 🔴 **Hard** | Advanced bugs that require deeper code analysis and problem-solving |
| 👑 **Boss** | A special challenge unlocked when the required Easy + Medium completion condition is met |

---

## 👑 Boss Challenge Unlock System

The Boss Challenge introduces a conditional progression mechanic.

- **Easy + Medium:** These stages together represent the 50% progression requirement.
- **Boss Unlock:** The Boss Challenge becomes available when the required Easy + Medium condition is satisfied.
- **Otherwise:** The Boss Challenge remains locked.

This mechanic encourages participants to demonstrate their debugging skills before attempting the special challenge.
