 # ⚔️ CRISIS-LABORATORY

### Interactive Debugging Arena | Sree Sakthi Engineering College

**CRISIS-LABORATORY** is a programming debugging arena designed to test students' coding knowledge, logical thinking, and problem-solving skills through progressively challenging debugging tasks.

Conducted at **Sree Sakthi Engineering College, Coimbatore**, this project transforms traditional debugging practice into an engaging technical challenge featuring multiple difficulty levels and a special Boss Challenge unlock mechanism.

The objective is simple: identify the bug, understand the problem, fix the code, and conquer the challenge.

---

## 🎯 About the Project

CRISIS-LABORATORY provides an interactive environment where participants solve programming errors across different difficulty levels.

The arena encourages students to improve their programming fundamentals, debugging techniques, analytical thinking, and confidence in solving coding problems.

## 🎮 Challenge Levels

| Level | Description |
|---|---|
| 🟢 **Easy** | Basic debugging challenges for testing programming fundamentals. |
| 🟡 **Medium** | Intermediate problems requiring logical thinking and code analysis. |
| 🔴 **Hard** | Advanced debugging tasks that challenge problem-solving abilities. |
| 👑 **Boss** | A special challenge unlocked when the required Easy + Medium progression condition is satisfied. |

## 👑 Boss Challenge Unlock System

CRISIS-LABORATORY includes a conditional Boss Challenge designed to reward participants for progressing through the initial levels.

- **Easy + Medium:** Participants must satisfy the combined 50% progression requirement.
- **Boss Unlocked:** The Boss Challenge becomes available when the required condition is met.
- **Boss Locked:** If the condition is not satisfied, the Boss Challenge remains unavailable.

This system encourages participants to demonstrate their debugging skills before advancing to the special challenge.

## 🚀 Getting Started

### Prerequisites
 
Install the following tools before running the project:

- [Node.js](https://nodejs.org/)
- npm, included with Node.js
- A web browser

### Installation 

**1. Clone the repository**

```bash
git clone https://github.com/sabith-todo/CRISIS-LAB.git
````

**2. Enter the project directory** 

```bash
cd CRISIS-LAB
```

**3. Install backend dependencies**

```bash
npm install
```

**4. Start the application** 

Check your `package.json` for the available scripts. If a `start` script exists, run:

```bash
npm start
```

If your project uses a different startup command, use the command defined in its configuration.
