## 🛠️ 4. How to Add Custom Teams from Google Sheets / Excel

### Method 1: Edit [`assets/js/teams-data.js`](file:///d:/Odyssey%20Event/CRISIS-LABORATORY/ai-odyssey/assets/js/teams-data.js) (Recommended)
Add new team objects inside the `PRECONFIGURED_TEAMS` array in [`assets/js/teams-data.js`](file:///d:/Odyssey%20Event/CRISIS-LABORATORY/ai-odyssey/assets/js/teams-data.js):

```javascript
{
    team: "YourTeamName",
    password: "YourPassword123",
    members: ["Member1", "Member2", "Member3"],  // 1, 2, or 3 members
    status: "approved"
},
```

---

### Method 2: Import from Excel / Google Sheets via Admin Panel
1. Open [`admin.html`](file:///d:/Odyssey%20Event/CRISIS-LABORATORY/ai-odyssey/admin.html) and sign in (`ODYSSEY` / `techodyssey`).
2. Click **`📋 Import from Excel / Sheets`** at the top.
3. Paste rows directly from your spreadsheet in CSV format:
   ```csv
   TeamName, Password, Member1, Member2, Member3
   ```
4. Click **`🚀 Import & Approve All Teams`**. All teams will immediately be registered, pre-approved, and ready to compete!
