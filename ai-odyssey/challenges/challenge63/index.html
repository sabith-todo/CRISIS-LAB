Var Variable Hoisting in Async Loops

Challenge #63 • 50 pts • Language: JavaScript

📋 Problem Description

A node status checker queries 5 microservice endpoints using a for loop with var. Because var is function-scoped rather than block-scoped, all asynchronous callbacks execute with the final incremented value i = 5. Diagnose and resolve the 3 distinct code errors present in the module.

🎯 Debugging Objective

Replace var with block-scoped let in the for loop declaration.
